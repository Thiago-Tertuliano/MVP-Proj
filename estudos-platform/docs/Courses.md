## 📝 Observações

Este arquivo funciona como um catálogo pessoal de estudos.

A classificação deve considerar **o assunto principal do material**, e não necessariamente a tecnologia utilizada.

Exemplo:

* Apache Iceberg → **Dados**
* Git / GitHub → **SRE / Infraestrutura**
* Python → **Desenvolvimento**
* LLMs / Prompt Engineering → **Inteligência Artificial**
* SAP FI → **SAP**
* Gerenciamento de Projetos → **Projetos**

Novos materiais podem ser adicionados diretamente na tabela correspondente.
